# Anleitung zur Benutzung

## Voraussetzungen
- Auf dem System muss **Python** installiert sein.

## Aufgabe 1 ausführen
1. Wechseln Sie in das entsprechende Verzeichnis der **Aufgabe 1**.  
2. Führen Sie die Datei **`main.py`** aus.  
3. Die zu verwendende Eingabedatei kann in der Datei **`load_input.py`** angepasst werden.

## Aufgabe 2 ausführen
1. Wechseln Sie in das entsprechende Verzeichnis der **Aufgabe 2**.  
2. Führen Sie die Datei **`main.py`** aus.  
3. Die Eingabedatei kann direkt in der Datei **`main.py`** angepasst werden.
